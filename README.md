# Readme
This repository is for the paper "Meta-learning-based delayless subband adaptive filter using complex self-attention for active noise control" on Neurocomputing.
## Datasets:
* ESC-50 is from https://github.com/karolpiczak/ESC-50
* Noise-92 is from http://spib.linse.ufsc.br/noise.html
* Nonspeech is from https://github.com/speechdnn/Noises/tree/master/Nonspeech
## Code:
optimizer.py is the prototype of the proposed model, and nn_complex.py is the neural network parts of the model.
